Retail Store Feedback Dashboard

GitHub Pages View

This repository contains a Spring Boot app for feedback sentiment analysis and dashboard visualization.

GitHub Pages can host only static files, so this page is a static project overview. To run the live dashboard with API endpoints, start the backend locally.

Tech Used
Java 21 Spring Boot Thymeleaf Stanford CoreNLP Gemini API Bootstrap Chart.js Maven
What This Project Does
  • Reads raw retail feedback from a text file.
  • Runs sentiment analysis using CoreNLP.
  • Enriches feedback with category and actionable insight using Gemini.
  • Shows summaries and feedback details in a web dashboard.
Run Full App Locally
./mvnw spring-boot:run

Then open http://localhost:8080/dashboard.
